A Snowflake agent that answers questions about what India reads on Wikipedia: Cortex Analyst (text-to-SQL on a semantic model) for numbers, Cortex Search over AI explanations for "why", with SQL guardrails and refusals. Every version is scored on the same golden set; this page shows the hill-climb.

How it works

Wikipedia Pulse (hourly)→Snowflake tables→ Guardrails→Router (Cortex LLM)→Cortex Analyst + SQL check/ Cortex Search + cited answer→Traces → new eval cases

Data questions are scored by running a reference SQL query on the same data and comparing results. "Why" questions are generated from real trending pages and judged for retrieval and faithfulness. Out-of-scope and unanswerable questions must be refused, not answered with invented numbers.
